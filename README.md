## 📌 Project Overview

Customer Demographics Study is a data analysis project that analyzes customer demographic information and spending behavior using Python.

The project explores customer age, gender, city, occupation, annual income, purchase frequency, and total spending to identify useful patterns and insights.

## 🎯 Objectives

- Analyze the demographic characteristics of customers.
- Understand the distribution of customers by age and gender.
- Identify customer distribution across different cities.
- Analyze customers based on their occupations.
- Study annual income and spending patterns.
- Analyze purchase frequency.
- Examine the relationship between income, purchase frequency, and spending.
- Present important findings using data visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
- GitHub

## 📊 Dataset

The dataset contains 500 customer records with the following attributes:

| Column | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Age | Age of the customer |
| Gender | Gender of the customer |
| City | Customer's city |
| Occupation | Customer's occupation |
| Annual_Income | Annual income of the customer |
| Purchase_Frequency | Number of purchases made |
| Total_Spending | Total amount spent by the customer |
